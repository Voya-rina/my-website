# F3 · AI 协作记录

本项目允许 AI 生成代码与协助调试。以下按阶段记录 AI 参与的部分、我的决策与验证方式。所有 AI 产出均经过本人逐条验证后才进入版本库，验证不通过的方案会被退回重做。

## 阶段一：结构与需求（G1）

- 我提供的输入：考核要求、前端目录示例、本人真实 GitHub 仓库列表
- AI 输出：目录结构方案、README 草稿、.gitignore 初版
- 我的决策：采用 docs / assets / src 的前端目录结构；项目数据全部来自本人真实仓库（ticket-request、QuestEdu、CaliEdu、ZZUPocket），不做虚构

## 阶段二：网站开发（F3 主体）

- AI 输出：`src/index.html`、`src/styles.css`、`src/app.js`、`src/data/projects.js` 初始代码，苹果式简约风（CSS 变量双主题、毛玻璃导航、卡片布局、响应式断点）
- 我的决策与验证：
  - 逐条对照 F3 必做要求自查：五大区块、数据与展示分离、主题持久化与降级、360px / 1280px 响应式、键盘操作、alt 文本
  - 用设备模拟器验证两种视口宽度；检查 Console 无未处理错误
  - 把分类筛选留作 G2 的增量开发任务，走 Issue → 分支 → PR 流程

## 阶段三：调试（F2 / K6）

- AI 输出：对 `querySelector("#theme")` 返回 null 的原因分析与最小修复
- 我的验证：在 Console 执行 `document.querySelector("#theme")` 复现返回 null，确认修复后连续点击可往返切换，Console 无报错

## 阶段四：Git 流程（G2 / G3）

- AI 输出：Issue 与 PR 文案草稿、revert 练习步骤、复现验证清单
- 我的决策：发现 PR 里功能与文档两个提交被误并为一个，用 `git reset --soft` 拆开重提；合并 PR 前亲自按 `G2_测试记录.md` 的 7 个用例实测
- 我的验证：在全新目录 clone 并按 README 启动，复现成功后才打 v0.1.0 标签

## 阶段五：展示区迭代（F3 增强）

多轮"AI 实现 → 我预览 → 提出修改 → 再实现"的迭代，每轮改动都本地预览确认后才提交：

- 布局：技能 / 项目卡片由自适应改为桌面端固定 2 列，消除 3+1 排布；头像接入 GitHub CDN 并加入顶栏
- 展示区：新增项目截图展示区（项目 → 展示 → 技能），左侧卡片随滚动 sticky 联动当前项目信息，并随筛选同步隐藏/显示
- 图片工程：按"浅色 / 深色镜像配对"从约 20 张候选截图中筛选整理为 22 张规范命名文件（`项目-主题-序号`），存放于 `assets/projectshot/`；QuestEdu 做成"网页控制台 + 手机端"组合行，比例经一轮修正（窄列错误地装下了宽图）
- 移动端：480px 宽度下展示区改为固定高度 + 横向滑动查看，保证截图文字可读；曾尝试"图内滚动"方案，体验不佳后整体回退
- 我的验证：每轮在本地服务预览滚动、筛选、主题切换与 Console，发现问题（如卡片初始高度测量在内容填充前执行导致叠放错位）要求 AI 定位根因修复

- 新增板块与交互：联系区改为胶囊卡片（邮箱 mailto 直达、QQ 点击复制带降级方案）、中英双语座右铭板块、技能区淡色词云背景（内容取自 SKILLS 数据，随机洗牌、相邻行反向、随页面滚动小幅漂移，prefers-reduced-motion 时静止）、与主题联动的页面底部背景装饰图
- 迭代修正：GitHub 图标 SVG 手绘路径失真 → 换用标准 Octocat 路径；座右铭中英文字号统一后再按需微调；词云从"·分隔 + 5 行大字"调为"空格分隔 + 10 行小字"
- 词云"横向拉满"实现时引入一个**死循环 bug**：补宽循环读取游离节点的 `scrollWidth` 恒为 0，永不退出，页面卡死转圈
- 我的排查与验证：先用无头浏览器对照实验（完整页挂起、去掉词云容器的副本正常）锁定范围，再对循环插桩实测，拿到 `sw=0 need=973` 的证据，定位根因为"元素挂载到 DOM 发生在测量之后"；修复为先 `appendChild` 再按真实渲染宽度补足内容
- 回归验证：无头浏览器确认页面完整渲染（10 行词云、4 张项目卡、技能卡、计数文案），并自动化点击"工具"筛选，验证展示区与筛选联动（ticket-request 可见、其余隐藏）
- 工程便利：根目录新增 `clicktorun.bat`，双击自动启动本地服务并打开浏览器（内容纯 ASCII + `%~dp0` 自引用，规避中文路径编码问题）

## 阶段六：文档整合与托管

- 我的决策：将各题作答汇总为个人答案文档；仓库 docs/ 仅保留题目硬性要求的留证材料（G1 Git 说明、F2 修复记录、G2 测试记录、G3 复现记录、K6 报告、本文件、截图），删除与文档重复的 F1 问答；文件按 `题号_内容` 重命名
- AI 输出：GitHub Pages 部署方案与 Actions workflow、根目录跳转页
- 我的验证：检查 workflow 触发条件与产物路径，确认相对路径在子目录部署下可正常解析

# AI 协作记录

本项目允许 AI 生成代码与协助调试。以下记录 AI 参与的部分、我的决策与验证方式。

## 阶段一：结构与需求（G1）

- 我提供的输入：考核要求（1.md）、目录示例、真实项目仓库列表
- AI 输出：目录结构方案、README 草稿、.gitignore
- 我的决策：采用 docs / assets / src 的前端目录结构；项目数据全部来自本人真实 GitHub 仓库，不做虚构

## 阶段二：网站开发（F3）

- AI 输出：`src/index.html`、`src/styles.css`、`src/app.js`、`src/data/projects.js` 的初始代码，苹果式简约风格（CSS 变量双主题、毛玻璃导航、卡片布局、响应式断点）
- 我的决策与验证：
  - 功能逐条对照 F3 要求自查：五大区块、数据与展示分离、主题持久化、360px / 1280px 响应式、键盘操作、alt 文本
  - 用开发者工具的设备模拟器验证 360px 与 1280px 两种宽度，导航折叠为汉堡菜单
  - 检查 Console 无未处理错误
  - 把项目分类筛选留作 G2 的增量开发任务，通过 Issue → 分支 → PR 流程实现

## 阶段三：调试（F2 / K6）

- AI 输出：对 `querySelector("#theme")` 返回 null 的原因分析与最小修复
- 我的验证：按 K6 文档中的步骤在 Console 复现验证，确认修复后连续点击可往返切换

## 阶段四：Git 流程（G2 / G3）

- AI 输出：Issue 与 PR 文案草稿、revert 练习步骤
- 我的验证：按 README 在全新目录 clone 并启动，确认复现成功后才打 v0.1.0 标签

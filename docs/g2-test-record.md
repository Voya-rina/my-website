# G2 · 分类筛选功能测试记录

对应 Issue：项目分类筛选（见仓库 Issues 页面）

## 验收条件（来自 Issue）

1. 选择某一分类后，只显示该分类下的项目，且计数与实际卡片数量一致
2. 点击"全部"后恢复显示全部项目
3. 键盘可以 Tab 聚焦筛选按钮，Enter 触发，焦点可见
4. 浏览器 Console 无新增未处理错误

## 测试方法

```bash
# 在项目根目录启动本地服务
python -m http.server 8000
# 打开 http://localhost:8000/src/index.html
```
